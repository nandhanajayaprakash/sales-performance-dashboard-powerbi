# sales-performance-dashboard-powerbi
Power BI Sales Dashboard analyzing 2.30M sales (2014-2017) | DAX, KPIs, Insights | West region top performer, Furniture low profit

## 📊 Overview
Analyzed 2.3M+ sales records (2014-2017) to identify revenue drivers, low-profit categories, and regional performance. Designed an interactive Power BI dashboard for data-driven decisions.

## 🎯 KPIs Tracked
- Total Sales: 2.30M
- Total Profit: 286.40K
- Profit Margin: 12.47%
- Quantity Sold: 9K

## 🔍 Key Insights
- **West region** is top performer in sales
- **Furniture** category shows lowest profit despite high sales
- **Q4 (Oct-Dec)** is peak season
- Technology sub-category generates highest profit margin

## 🛠️ Tools Used
Power BI | DAX | Power Query | Data Modeling | KPIs & Slicers
